# ⏱️ AlgoBench — Algorithm Design & Benchmarking

Design & Analysis of Algorithms: theory vs measured performance, across eight paradigms.

## 🔗 Live links

- **Website (GitHub Pages):** https://harshini-suresha.github.io/algobench/
- **Notebook in Colab:** https://colab.research.google.com/github/Harshini-Suresha/algobench/blob/main/AlgoBench.ipynb
- **Streamlit app:** https://algobench-ezdmvjxxnpfq7jrkazz2xv.streamlit.app/

## 📁 Files

- `index.html` — static site, live in-browser benchmarks (same as `AlgoBench.html`). Hosted on GitHub Pages, works offline.
- `AlgoBench.ipynb` — self-contained notebook, runs in Jupyter or Colab (badge above).
- `streamlit_app.py` + `algobench.py` — `pip install -r requirements.txt && streamlit run streamlit_app.py`
- `results.csv` — 162-point reference dataset generated by `algobench.py`

## ▶️ Run locally

```bash
pip install -r requirements.txt
jupyter notebook AlgoBench.ipynb      # or open in Colab
streamlit run streamlit_app.py        # interactive benchmark app
open index.html                       # this site, works offline
```
